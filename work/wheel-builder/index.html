Wheel Builder

A procedural Houdini HDA for building a wheel from two independent outputs: alloy and tire. Its controls cover fitment, tire profile, alloy-face patterns and tire tread families.

The walkthrough demonstrates the neutral-gray modeling prototype; it is a general-purpose modeling asset, not a vehicle fitment certification.

Role: Concept, procedural design, HDA build and demo Stack: Houdini 20.5 · Python SOP · procedural geometry Outputs: OUT_ALLOY · OUT_TIRE · combined preview Status: HDA v1.2 on GitHub
