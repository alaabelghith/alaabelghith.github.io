# alaabelghith.github.io

Portfolio site for Anything Visual — AI + 3D visual production by Alaa Belghith.

One self-contained HTML file. No build step, no framework, no tracker. YouTube embeds are
click-to-load facades: a local thumbnail is shown and the `youtube-nocookie` iframe is only
constructed when a visitor actually asks to play, so the page makes no third-party request
until then.

To add a piece: append to the `WORK` array in the script block and drop a
`thumbs/<videoId>.jpg` beside it.

Served by GitHub Pages from the default branch.
